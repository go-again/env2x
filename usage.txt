 env2x outputs env variables in
 json, yaml, env or string formats

 Usage:
   %s [-p] VAR1 [VAR2] [VAR3{=value}] ...
     -p     pretty print json
   %s VAR1 [VAR2] [VAR3{=value}] ...
   %s  [-s] VAR1 [VAR2] [VAR3{=value}] ...
     -s     single line env
     -e     add export
   %s VAR [file] [mode]
     default mode 0644
